# Discord Help Bot — Railway

## Configurare
1. Creează un proiect Railway și alege **Empty Project**.
2. În **Variables**, adaugă secretul `DISCORD_TOKEN` cu tokenul nou generat în Discord Developer Portal.
3. Încarcă aceste două fișiere (`package.json` și `index.js`) sau conectează un repository.
4. Railway va rula automat `npm start`.
5. Invită botul cu scope-urile `bot` și `applications.commands`, plus permisiunile necesare.

Nu pune tokenul în fișiere sau în chat. Creează rolul `Verified` pe server pentru comanda `/verify`.
